# $PUHU Whitepaper
**The Chronically Sleepless Night Owl**

## 1. Introduction

$PUHU is a memecoin built on the Solana blockchain.

It represents a chronically sleepless, slightly grumpy night owl. It hates empty promises, exaggerated roadmaps, and “to the moon” lies.

$PUHU focuses only on three things:
- Community
- Chart
- Continuous supply reduction

The project was launched via fair launch with zero team allocation and zero private sales.

---

## 2. Vision & Main Goal

**Vision:**  
To become the most honest, least promising, and most deflationary memecoin on Solana.

**Main Goal:**  
To systematically reduce the circulating supply of $PUHU through regular buybacks funded by ecosystem revenue, making the token scarcer and more valuable over time.

## 4. Owl Raid

Owl Raid is the official game of the $PUHU ecosystem.  
It is a night-themed **Idle + Clicker + PvP Arena** game.

### Core Features:
- $1 entry fee (paid in SOL) to unlock the game
- Main currency: Feathers
- Click the owl or use auto-upgrades to earn feathers
- Upgrade system (click power, multipliers, critical hits, auto production)
- Prestige system for permanent multipliers
- Skin system with bonuses
- Inventory & Equipment (Weapon, Armor, Shield, Helmet) that increase Combat Power
- Daily Login Bonus with streak rewards
- Referral system (earn 10% of your referrals’ feathers)

### Arena (PvP):
- 5 free fights per day
- Option to buy +5 extra daily fights for 7 days ($1)
- Turn-based combat using Attack, HP, Defense, Crit, and Block
- Winner steals feathers from the loser
- Military rank system (Private → General)
- Combat Power (CP) and global leaderboard

Users can:

- Create giveaways with SOL or any SPL token

### Key Features:
- Permanent Verified badge (5 USDC)
- 1–10 winners selection
- Duration options from 1 hour to 7 days
- Automatic winner drawing
- Top Distributors ranking
- Most Followed ranking
- Full profile history
